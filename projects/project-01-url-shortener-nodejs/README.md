# URL Shortener Service

## 🧠 System Design Overview
- Simple service to shorten long URLs
- Redirect users to original URL when short link is accessed
- Focus on scalability & low latency

## ⚙️ Tech Stack
- Node.js
- Express.js
- MongoDB (for URL storage)
- Redis (optional caching layer)

## 🚀 How to Run
- Clone repo
- Navigate to this folder
- Install dependencies with `npm install`
- Start with `npm start`

## 📚 Lessons Learned
- Handling URL collisions
- Designing efficient database schemas
- Caching strategies
